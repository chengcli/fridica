# Fridica 0.4 design document (sources)

One RST file per section, `index.rst` (title page, contents, includes) and `fridica.yaml`
(the same rst2pdf stylesheet as `docs/rst/`, with a slightly smaller code font and DejaVu Sans Mono
for code, because the ASCII diagrams use box-drawing characters that Courier lacks; `fonts-dejavu`
on Debian/Ubuntu, `dejavu-sans-mono-fonts` on Fedora).

Rebuild:

```sh
python -m pip install rst2pdf          # or: pip install -e '.[docs]'
cd docs/rst-0.4
rst2pdf index.rst -s fridica.yaml --font-path /usr/share/fonts/truetype/dejavu \
    --fit-background-mode=scale -o ../fridica-0.4-design.pdf
```

The numbers in section 3 were computed from `~/.local/state/fridica/state.sqlite3`
at the snapshot time named on the title page; they are not regenerated by a build.
