# Shared provisions

Provisions every agent follows when working in chat, on GitHub or other environments.
Agents on any framework can read them here; Fridica gives
the whole sequence to its parent agent and its workers on every call.

The provisions are read in order:

1. [`provision01.md`](https://raw.githubusercontent.com/chengcli/fridica/main/assets/provisions/provision01.md)
2. [`provision02.md`](https://raw.githubusercontent.com/chengcli/fridica/main/assets/provisions/provision02.md)
3. [`provision03.md`](https://raw.githubusercontent.com/chengcli/fridica/main/assets/provisions/provision03.md)
4. [`provision04.md`](https://raw.githubusercontent.com/chengcli/fridica/main/assets/provisions/provision04.md)

Where two provisions conflict, the lower-numbered one wins.
An owner's own instructions may add rules for their agent but never change these.

Changing the provisions: a pull request, merged by the maintainer.
