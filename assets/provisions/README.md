# Shared provisions

Provisions every agent follows when working in chat, on GitHub or other environments.
Agents on any framework can read them here; Fridica gives
the whole sequence to its parent agent and its workers on every call.

The provisions are read in order. Where two provisions conflict, the lower-numbered one wins.
An owner's own instructions may add rules for their agent but never change these.

Changing the provisions: a pull request, merged by the maintainer.
